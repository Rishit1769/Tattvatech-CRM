# Phase 2 — Projects

## Goal

Make the sales-to-delivery handoff operational and visible.

## Deliverables

- Projects with client, scope, owners, dates, value, payment structure, and deployment notes.
- Project statuses and detail tabs.
- Tasks with assignment, status, priority, due dates, blockers, and completion notes.
- Milestones with delivery/payment information and invoice requirement.
- Project files and activity.
- Sales handoff summary containing promised scope, price, deadlines, requirements, contacts, proposal, and risks.

## Acceptance checks

- A project cannot exist without a client.
- Tasks cannot exist without a project.
- Project finance and activity views link to related records.
- Project state is understandable without searching other modules.
