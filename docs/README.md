## Source of truth

`dream-build.md` remains the master product specification. These documents reorganize its decisions for day-to-day implementation. If a document appears to conflict with the master specification, the conflict must be resolved explicitly before coding.

## Fixed decisions

- Next.js, TypeScript, Tailwind CSS, MySQL, and MinIO are the application stack.
- Nodemailer is the approved server-side email utility.
- The CRM is one Next.js application. Prisma is now the approved MySQL access layer; do not introduce a separate backend, GraphQL layer, Redis, or microservices without an explicit architecture decision.
- Version 1 finance entry is manual.
- Invoices are generated by the CRM, stored in private MinIO, and referenced from MySQL.
- TattvaTech-controlled core services belong on the ASUS ROG server; the college-hosted server is non-core.
- Client commercial production deployments are client-controlled/client-provided infrastructure.

## Product north star

The CRM is the company’s operational memory. The core relationship is:

`Lead → Meeting → Proposal → Won → Client → Project → Payment → Invoice → MinIO file → Email → AMC`

The system succeeds when the team no longer needs to search WhatsApp to determine the current state of a deal, client, project, payment, or incident.
